# Analisis_sentimen_menggunakan_Neural_NetworkKK
Proyek analisis sentimen pada tweet terkait mitigasi bencana menggunakan metode Neural Network (MLPClassifier) dengan ekstraksi fitur TF-IDF. Sistem ini melakukan preprocessing teks, pelabelan sentimen positif, negatif, dan netral, serta menampilkan hasil prediksi dan evaluasi model melalui dashboard Streamlit.
